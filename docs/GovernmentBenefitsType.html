GovernmentBenefitsType

A Schema.org Enumeration Type

This term is in the "new" area - implementation feedback and adoption from applications and websites can help improve our definitions.
Thing > Intangible > Enumeration > GovernmentBenefitsType
  • Canonical URL: https://schema.org/GovernmentBenefitsType
  • Check for open issues.
GovernmentBenefitsType enumerates several kinds of government benefits to support the COVID-19 situation. Note that this structure may not capture all benefits offered.

Instances of GovernmentBenefitsType may appear as a value for the following properties
PropertyOn TypesDescription
serviceType Service The type of service being offered, e.g. veterans' benefits, emergency relief, etc.

Enumeration members

  • BasicIncome
  • BusinessSupport
  • DisabilitySupport
  • HealthCare
  • OneTimePayments
  • PaidLeave
  • ParentalSupport
  • UnemploymentSupport
